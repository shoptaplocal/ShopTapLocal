## Replace the current GitHub files
1. Open the Taplocal repository.
2. Delete the old index.html, styles.css, and script.js.
3. Upload the new V3 index.html, styles.css, and script.js.
4. Commit changes.
5. GitHub Pages will automatically redeploy in about 1–5 minutes.

The ZIP file itself should not be uploaded to GitHub Pages.
